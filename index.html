Supabase Backup to Google Drive

A personal, single-user backup tool.

What this app does

This is a small personal automation tool. It runs on a schedule in the developer’s own private GitHub repository and copies the developer’s own Supabase database backups and Supabase Storage files into a folder named supabase-backup in the developer’s own Google Drive account.

How it uses Google Drive

  • It uses only the drive.file scope, which lets the app see and manage only the files and folders that the app itself created.
  • It cannot read, list, or modify any other file in the Google Drive account.
  • It is used only by its developer, with the developer’s own Google account. It is not offered to the public and does not collect data from any other users.

Privacy

Please read the Privacy Policy for details on how Google user data is accessed, used, stored, and shared.
