Privacy Policy

App: Supabase Backup to Google Drive  ·  Last updated: November 10, 2026

1. Overview

Supabase Backup to Google Drive (“the app”) is a personal automation tool created and used solely by its developer. It is not distributed to or used by the public. This policy explains how the app accesses, uses, stores, and shares Google user data.

2. Google user data the app accesses

The app requests one Google OAuth scope: https://www.googleapis.com/auth/drive.file. With this scope the app can access only the files and folders that the app itself creates in the authorized Google Drive account (a folder named supabase-backup and the backup files inside it). The app cannot view, list, or modify any other file in Google Drive. The app does not access Gmail, Contacts, Calendar, profile information, or any other Google user data.

3. How the data is used

The app uses this access for one purpose only: to upload, and to delete after a retention period, backup files that the app created in the supabase-backup folder. Google user data is not used for advertising, analytics, profiling, or any other purpose.

4. How the data is stored

The app stores no Google user data of its own. The only Google-related credential kept is an OAuth token for the developer’s own Google account, which is stored as an encrypted secret in the developer’s private GitHub repository settings and is used only by the scheduled backup workflow. The backup files themselves are stored in the developer’s own Google Drive and, for a short period, as private build artifacts in the same private GitHub repository.

5. Sharing and disclosure

The app does not sell, share, transfer, or disclose Google user data to any third party, and no person other than the developer has access to it. The app does not allow humans to read user data except as needed by the developer to operate their own backups.

6. Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Data retention and deletion

Backup files in Google Drive are retained for a limited period and then deleted automatically by the app. You can revoke the app’s access at any time at myaccount.google.com/permissions, and delete the supabase-backup folder from Google Drive at any time.

8. Changes to this policy

This policy may be updated from time to time. The “Last updated” date at the top of this page shows the date of the latest revision.
